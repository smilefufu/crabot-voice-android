# 设备所有者激活实施计划

日期：2026-10-16
状态：整组设计已确认，按后端[实施计划](https://github.com/smilefufu/crabot-docs/blob/main/superpowers/plans/2026-10-16-voice-device-owner-activation-implementation.md)推进。跨端类型唯一见 protocol-voice §13。

| 步骤 | 验证方式 |
|---|---|
| A1：在 Identity 共用逐段有效性、三对现有 matches 一致性及均值验证。 | 同人三段成功；少/多段、多人/重叠、无声、非法特征或比对、任一低分及均值失效拒绝。日常识别既有规则不变；公开 JNI 与模拟模型证据分开。 |
| A2：SecureStore 新加密版本允许仅所有者未配对，稳定档案独立于当前样本；保存映射与待回执。 | 先备份再原子替换、失败保旧；无网保存/重启，身份不因列表变化/删样本/重录而转移。测试仅隔离存储。 |
| A3：MainActivity/VoiceController 引导名字和三段采样，一次开始后自动逐段，无 ASR/TTS 依赖；完成才进扫码。 | 无网/权限拒绝/模型未就绪/取消/后台/60 秒超时明确状态；原音频清空、麦克风释放，旧回调不复活。 |
| A4：Wire/TerminalConnection 对齐 wire6 所有者核对、paired 映射、owner_saved 与结果恢复。 | 先原子保存再回执；描述变更拒绝，断网/写盘失败/丢响应仍沿原操作，不重建身份；只拿凭据不显示激活成功。 |
| A5：旧版仅依后台唯一 Master + 本机有效登记采用所有者引用；最终完成保持关麦。 | 保留 FuFu 配对/ID/向量，缺依据不认主或清数据；服务未配提示与认主成功分别显示。 |
| A6：定向 JVM/隔离仪器测试、APK 构建、简化检查及最终 diff review。 | 与后端隔离实例验新流程；真实手机保留数据统一升级在整组完成后，真人首次录入与现有设备升级分别验收。 |

复用边界：普通已配对登记仍需自己的现场许可；新采样只复用无场景验证层，不把后台 enroll 改成任意远程开麦。保存向量不等于好友创建成功，状态依后台持久结果。standby/response_end 不用于首次激活，完成后始终关麦。当前仅准备实现，未安装 APK 或改变真实密文。
