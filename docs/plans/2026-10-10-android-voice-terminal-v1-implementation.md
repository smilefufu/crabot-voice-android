# Android 语音终端一期实施计划

2026-10-11 修订：身份与联系人 spec 已确认；接口唯一依据 `smilefufu/crabot-docs/protocols/protocol-voice.md` v0.2.0，终端版本 2。实现分支 `feat/android-voice-v1`；本仓不走 PR，完成相关测试与本次 diff review 后直接提交、推送 main。Crabot 后端仍按主仓 PR 流程交付。

| 步骤 | 实现范围 | 验证方式 |
|---|---|---|
| 1 协议与本地兼容 | 配对/hello 版本 2、登记属于联系人、destinations 去 kind；旧配对显式不兼容 | v1/v2 拒绝；TLS/认证等待/Keystore/有限帧回归；不自动清空旧数据或实验向量 |
| 2 身份与内容 | 内容完整性单独检查；零登记/unknown/短簇及候选相近 uncertain 完整提交；分段/重叠失败不提交 | JVM 区间/重叠及 native 公开音频测试；陌生人不继承旧名字，同一匿名簇结果一致，向量不上传 |
| 3 界面与采样 | 渠道联系人声纹任务及现场确认；逐段显示联系人/陌生人/身份未确认；真实服务地址 | 重登新样本 ID 保持联系人；撤销清除；完成样本不声称 Friend 授权；默认关麦和前台约束保持 |
| 4 联调与交付 | 后端完整群轮次、实际播放、生命周期；重构建 0.2.0 debug APK并核验签名/hash | 原 JVM/禁音频 ARM64 测试，配套协议/Channel/APK 版本记录；真人 B、独立登记测试集、AEC/KWS/功耗/50轮延迟分别待实际条件验收 |

模型/hash/依赖基线不变，不增加 ASR/TTS 权重或后台录音。提取不到向量可作为 identity uncertain，分段/聚类失败不能伪造匿名时间线；不保存所有陌生人的声纹。各失败继续释放有界 RAM/采音/播放，不重传旧音频。私聊与 Agent 登记工具留待后续 spec。
