# Android 任务反馈实施计划

日期：2026-10-17。配套spec已由用户确认，跨端唯一契约为protocol-voice v0.7.0 / wire7。

| 步骤 | 验证方式 |
|---|---|
| 先写播放接纳与回执回归 | 静音/忙碌/错误连接/错误turn不接纳；普通reply与notification分开，实际播放回执可恢复且不会播放音频。 |
| 对齐wire与状态 | 新握手用7，已保存3–6配对保留；heartbeat明确是否允许发声及当前阶段。 |
| 接入播放准备与完成 | 预留后才接音频，拒绝无TTS；通知不冒充输入turn，不额外开麦或接话；状态变化立即释放。 |
| 持久回执与待通知标记 | 只有真实播放完成生成completed；重连补原回执至确认，不补旧音频；显示安静提醒，正文由原主控生成。 |
| 构建与真机 | JVM单元/Debug及测试APK构建，保持声纹/配对数据；功能整组就绪后再覆盖安装和真人体验，不部署半套wire。 |

本仓按约定测试后直接main；与后端协议和实现版本一起记录，不以编译代替真机听感，不跑会清除真实手机数据的完整仪器测试。

候选实现：0.6.1（versionCode15）/wire7。已通读本次diff：普通reply只接当前turn，notification只在前台、明确允许发声且空闲时预留；通知仅恢复仍有效的原待机状态，不另开8秒接话；回执按原配对范围保留到后端确认。正文、PCM和原始配对凭据不写入回执文件。

验证：JVM23项通过，Debug和AndroidTest APK均编译成功。测试APK尚未在设备执行，未覆盖安装，不改现有手机的配对/声纹；后台、锁屏、焦点、真实播放与声纹采样需协调后端一起验收，不能将编译结果当作体验已通过。
