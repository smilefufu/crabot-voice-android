# APM 回声消除的隔离构建与公开音频验证

依据：已确认的[自然语音设计](../specs/2026-10-27-natural-voice-turn-taking-design.md)中 AEC 组件与 A3 步骤。仅推进已有设计，不更换判停模型、调门槛、修改产品协议/提示词或部署；不连接 ADB、不采音或播音。这里的软件混音不能替代真实扬声器/麦克风实验。

| 步骤 | 验证方式 |
|---|---|
| 固定构建输入 | 沿用 APM 1.3 的已记录发行源码 SHA；校验其 wrap 内固定的 Abseil 源码及 Meson 补丁。独立工具环境，原 ASR/TTS 和系统环境不变。 |
| 宿主及 Android 构建 | 原上游源码编译宿主及 ARM64/API29，使用既有 NDK；不复制到 App 或安装手机。记录错误、构建时间、产物大小及依赖。 |
| API/采样验证 | 按上游每帧 10ms、先 reverse 后 capture，float render 24kHz、capture/output 16kHz；校验所有返回码、输出长度与有限值。原产品 20ms 帧将来需拆分，此轮不接入。 |
| 固定公开混音对照 | 30 秒固定信号，APM 默认 AEC3 开/关及空参考对照；仅开 AEC，不开 AGC/降噪掩盖残留。公开中文原样本 hash 已固定，输入混音与全部对照列表预测前保存。 |
| 量度与边界 | 报仅回声的分段能量衰减、近端单讲/双讲的电平与波形相似度、异常、10ms 处理墙钟 P50/P95/max。先看正确数据流与明显损伤；不从这些数字推断手机效果或业务误唤醒数。 |

固定输入：此前公开 sherpa `fangjun-sr-1.wav` 作为远端，`leijun-test-sr-1.wav` 作为近端，沿原 sources.json 校验。去直流、统一到固定 RMS 0.05；30秒远端循环，在第14秒暂停0.6秒后恢复；近端分别置于第10秒与第22秒，各最多6秒。合成回声为远端重采样后的80/95/110ms延迟、0.45/0.15/0.08增益叠加；不模拟真实房间，只核对已知参考是否被正确消费。所有场景保持相同生成与处理规则，不按结果修改混音。

对照为 near_only/off、near_only/on、echo_only/off、echo_only/on、echo_only/on_no_reference、double_talk/off、double_talk/on，共7项，每项全新 APM 状态；near_only 与 no_reference 的 render 均为零。报告前5秒适应与后续分别统计，不能删掉前段失败宣布全段通过；相似度同时给出未对齐与最多10ms互相关对齐值，并明确对齐偏移。保留原始输出在隔离目录，不提交音频。没有预先证明的声学门槛，不制造“达到某dB就通过整套自然打断”的结论。

停止条件：摘要不符、依赖无法核验、API/长度错误或显著数值异常则停止相应实验并保留原因；不改上游算法掩盖失败。真实 render 游标/采音时钟、路由、系统 AEC 禁用、手机性能/耗电、VAD和身份兼容仍需后续实现及设备证据。

首次7项结果保留后追加一项归因诊断：仅开放上游 `GetLinearAecOutput` 旁路观察，不调消除器参数，复用原 near_only/on、echo_only/on、double_talk/on 输入；核对普通输出摘要与原结果完全一致，再比较线性输出和最终输出的近端损伤。它只用于区分线性消除与后续抑制，不替换产品输出或修改原始评分。

随后用原 silero 权重 SHA、sherpa-onnx 1.13.8 与原 VAD 配置（0.5、min_speech/silence 0.05秒、max_speech16秒），将7项普通输出及3项线性输出量化为PCM16再按原320样本逐帧喂入，与当前short→float模型入口一致；不对残余回声另做响度归一化。记录仅回声中的VAD阳性帧、近端两段首次阳性时间及阳性区间；与near_only/off对照。不调整阈值/时长，不将VAD帧等同于业务误触发；公开软件回声的结果不代替真实声学、身份或插话确认验收。
