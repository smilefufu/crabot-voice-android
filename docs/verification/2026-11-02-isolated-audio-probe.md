## 需要现场配合时的有限步骤

先向用户说明并获准安装、采音与播放；安装前只读核对设备、包名和 APK 摘要，沿用原 ADB 密钥/服务器，不重启 ADB、不撤销授权。测试工具没有自动启动或远程启动采音的入口。

1. 用户点“测试扬声器回声”，保持安静。最多 12 秒，只播放固定公开句子；原 AudioRecord/AudioTrack、统一时钟、APM、VAD 实际运行。检查时间戳/采音连续性、是否有真实 render anchor、是否误确认讲话及资源收口。
2. 第一步未暴露故障再做第二步：用户点“测试开口插话”，在播放期间自然读屏幕上的一句话。候选调用同一产品播放器暂停；确认后报告原实际游标并停止，假候选从原位置恢复。仍最多 12 秒，结束页一直保留。
3. 任一步失败即停止，不要求重复整批。页面只保存计数、耗时、时钟和实际回执的 JSON；音频只在原有有界内存中处理，不落盘、不上传，不触及正式 App 目录。

正常结束/停止按钮/后台离开均关闭采音。焦点、路由、组件或时钟异常也结束，释放异常明确显示，不伪装关麦成功。不调整音量、不创建新的设备授权或业务请求。

候选到确认的间隔只是本地代理指标，没有独立标注的真人开口时刻，不能拿它直接声称 P95 400ms 自然插话门槛通过。时钟 ppm 是有限录放期间的观测，不能外推全天漂移。现场只验证这一专项；不重测声纹、不调用 ASR/Agent/TTS、不重启 Crabot，不宣称中文停顿或三轮对话已验收。

## 构建

设置原 SDK/JDK 环境，先构建产品 APK，再执行：

```sh
python docs/research/2026-10-27-natural-turn-taking/build-device-probe.py --output <新建隔离构建目录>
```

脚本只复制指定产品文件、按 SHA 核验公开参考与模型、从产品 APK 抽取同字节原生库，然后离线构建独立 APK；不会安装或调用 ADB。不复用旧任务或业务目录作为测试输出；目录不是此前探针生成时拒绝覆盖。
